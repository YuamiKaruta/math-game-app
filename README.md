# 小学生の計算ゲーム 🧮

スマホやタブレットで楽しめる小学生向けの計算練習ゲームです。

## 特徴
- 足し算、引き算、掛け算の3つのモード
- イージー、ノーマル、ハードの3つの難易度
- 回答時間に応じたスコアシステム
- 詳細な結果分析とグラフ表示
- スマホ・タブレット対応のレスポンシブデザイン

## 使い方
1. ゲームモードと難易度を選択
2. 50問の計算問題に挑戦
3. 結果を確認して次回の目標を設定

## 技術スタック
- Streamlit
- Python
- Pandas
- Matplotlib

## ローカル実行
```bash
pip install -r requirements.txt
streamlit run math_game.py
```
